## MAGA Git Workflow
- Projects configured as `protect-main` or `worktree-only` block direct edits/commits on protected branches (or primary checkout). Load `git-workflow` or run `~/.gemini/config/plugins/maga-git-workflow/bin/wt.mjs` to create an isolated worktree.
- Client-side hooks act as a soft safety rail alongside server-side remote branch protection.
